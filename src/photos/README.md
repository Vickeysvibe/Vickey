# Photos

Drop images here (`.jpg`, `.png`, `.webp`, `.avif`) and they appear in the
Photography section automatically.

- **Order + caption from the filename:** `01-marina-beach-sunset.jpg` is shown
  first, captioned "Marina beach sunset". The number is optional.
- **Keep them light:** resize to about 2000px on the long side (roughly
  300–600 KB each) before adding. On macOS:
  `sips -Z 2000 --setProperty formatOptions 80 photo.jpg`
